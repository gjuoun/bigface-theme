# Bigface

A dark color theme, ported to the tools you use. Started in 2018 as a
[JetBrains scheme](https://plugins.jetbrains.com/plugin/10988-bigface-color-scheme);
now one palette (`palette/bigface.json`) generates a theme for each tool.

Dark only. Run `bun run themes` to regenerate `themes/` from the palette.
